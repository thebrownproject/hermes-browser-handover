# Security

This plugin can expose an authenticated browser session to its authorised viewer.
Treat authentication and human-control failures as security-sensitive.

Do not put credentials, cookies, private handover links, personal data or payment
information in an issue. Use GitHub private vulnerability reporting when available;
otherwise request a private reporting channel without posting exploit details.

Only unreleased development scaffolding is currently available. No security audit,
production readiness or supported payment integration is claimed.
